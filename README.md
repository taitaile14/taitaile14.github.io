# Mingtai Zhang — Academic Homepage

Source for [Mingtai Zhang's academic homepage](https://taitaile14.github.io), built for research communication and PhD applications.

The site presents publications, research experience, systems built, education, honors, and two downloadable CVs. It is based on the open-source [AcadHomepage](https://github.com/RayeRen/acad-homepage.github.io) template and is deployed with GitHub Pages.

Papers under double-blind review are listed without title, venue, or co-author list until notification.

## Local preview

```bash
./preview.sh
```

Then open `http://127.0.0.1:4000`.
